# GDPR and ePrivacy

Learn about GDPR and ePrivacy compliance with Sealmetrics. This section addresses the legal framework that enables consentless analytics in the European Union.

Two separate rules decide whether analytics needs consent: the [ePrivacy Directive](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32002L0058) (Article 5(3)) governs what you store on or read from the device, and the [GDPR](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32016R0679) (Article 4(1)) governs the processing of personal data. Sealmetrics triggers neither — nothing is written to the device, and the stored dataset holds no personal data. These pages explain how session markers fit into that framework and when a session identifier does require consent.
